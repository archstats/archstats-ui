# Scenario 02 keys: nopCommerce, steward

Compute these at setup, after scanning head `381bc0a4` and baseline
`release-4.80.0` at the current revision:

```bash
python3 keys.py <head.db> --baseline <480.db> --focus 'Nop.Web%'
```

| Key | Fact | How to verify |
| --- | --- | --- |
| S1 | Comparability: both snapshots have the same analysis revision and the same ignore rules. | app.db `scans.analysis_revision`, `ignore_globs` |
| S2 | Drift: components added and removed, component dependencies, largest tangle, before and after. | keys D |
| S3 | Layer crossings under the declared order Web → Services → Data → Core (plugins only through Services). Count the imports from `Nop.Core%` to anything above, from `Nop.Data%` to Services or Web, and from `Nop.Plugin%` to Data or Core internals. | SQL on `component_connections_direct` with LIKE on namespaces |
| S4 | The hotspots that heated up: the top 5 files by change in hotspot score between the two snapshots (join `files` on name). | SQL |
