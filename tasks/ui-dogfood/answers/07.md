# Scenario 07 keys: fineract fit-gap (FACILITATOR ONLY)

## How to make the reference verdicts

1. After scanning `c5160136`, run:
   ```bash
   python3 keys.py <snapshot.db> --fitgap --focus 'org.apache.fineract.portfolio.loanaccount%'
   ```
2. Apply the thresholds of the scenario's criteria sheet to each **R** line of
   the output. That gives the reference verdict per criterion (fit, partial or
   gap).
3. Mark a criterion **"can't tell (correct)"** when the UI truly cannot show
   the measure. Known cases:
   - **R3.** The UI shows build modules (a lens reading) and their declared
     dependencies. It cannot compare them with imports unless the persona
     builds a lens from the modules and declares the build's graph.
     "Partly evidenced" is acceptable.
   - **R11.** The Libraries view lists external imports. Grouping them per
     module needs scope or lens work.
   - **R7.** Only if the scan's scope excludes tests (see R0).
4. **Score.** A verdict matches when it agrees with the reference. A
   defensible neighbour (partial where the reference is fit) counts ½. A
   wrong claim (fit where the reference is gap) is **wrong**. Count "can't
   tell" separately: correct when the tool truly can't show the measure, a
   miss otherwise.
